# Git — Local Workflow

## Objective
Learn how to track, prepare, and save changes locally using Git.

## Important Commands

- `git status`: Checks the state of your files.
- `git add`: Prepares changes for the next commit.
- `git commit`: Saves the prepared changes in Git history.
- `git push`: Uploads commits to GitHub.

## Workflow

```bash
git status
git add index.html
git commit -m "Update index.html"
git status
```

## Exercise Deliverable

1. Create a `commandes.md` file at the root of your project.
2. Write the Git commands used in the exercise.
3. Stage and commit the file.
4. Push the changes to GitHub.

## Summary

The local Git workflow allows you to check, prepare, and record changes before uploading them to GitHub.
